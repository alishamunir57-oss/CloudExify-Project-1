# 📖 Project 1 — Personal Expense Tracker

## Project Overview

The **Personal Expense Tracker** is a console-based financial management application developed to help users record, organize, and monitor their daily expenses efficiently.

The system allows users to maintain expense records, categorize transactions, search expenses, generate spending summaries, and store data permanently using file handling techniques. The project demonstrates practical implementation of data validation, modular programming, and persistent storage.

---

## Key Features

### 💰 Expense Management

- Add new expenses with automatic Expense ID generation
- Record:
  - Expense Name
  - Amount
  - Date
  - Time
  - Category
- Update existing expense records
- Delete expenses by ID

### 🔍 Search & Filter

- Search expenses by:
  - Expense Name
  - Date
- Filter expenses by category
- View all recorded expenses

### 📊 Expense Analytics

- Calculate total expenses
- Generate category-wise spending summary
- Display percentage of spending in each category
- Organize expenses into:
  - Food
  - Transport
  - Shopping
  - Bills
  - Other

### 💾 Data Persistence

- Save expense records to text file
- Automatically load previous records on startup
- Preserve data between program executions

# 📖 Project 1 — Student Management System

## Project Overview

The **Student Management System** is a console-based application designed to simplify the management of student academic records. It enables users to maintain complete student profiles, manage academic performance, track attendance, and generate detailed reports.

The project follows a modular programming approach where each feature is implemented through reusable functions, resulting in clean, maintainable, and scalable code.

---

## Key Features

### 👨‍🎓 Student Management

- Add new student records with automatically generated unique IDs
- Store complete student information including:
  - Student Name
  - Father's Name
  - Contact Number
  - Email Address
  - Class
- Prevent duplicate student entries
- View complete student records
- Remove student records with confirmation

### 📚 Academic Management

- Add multiple subjects with individual grades
- Edit grades for any subject
- Automatically calculate:
  - Average Marks
  - Percentage
  - Letter Grade
  - Performance Remarks
  - Student Position

### 📊 Student Services

- Search students by Name or Student ID
- Update attendance percentage
- Display complete academic profiles

### 📈 Reporting & Analytics

- Generate professional student report cards
- Generate class performance reports
- Calculate:
  - Overall Class Average
  - Highest & Lowest Performer
  - Pass/Fail Statistics
  - Student Ranking
  - Subject-wise Class Average

### 💾 Data Persistence

- Save student records to CSV
- Load student records from CSV
- Export individual report cards as formatted text files
